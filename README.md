## 概要

スマートフォンのBluetooth（BLE）電波を利用し、持ち主が近づくと自動で開き、離れると自動でロックされる「傘の盗難防止IoTシステム」です。
ESP32とサーボモーターを組み合わせたハードウェアと、バックグラウンドで安定して電波を発信し続ける専用のAndroidアプリをゼロから開発し、完全ハンズフリーでのスムーズな鍵の開閉を実現しました。

## システム構成

[ 専用Androidアプリ ]
  │
  │ (BLE アドバタイズ発信 / 特定のオリジナルUUID)
  │ ※バックグラウンド(Foreground Service / WakeLock)で常時発信
  ▼
[ ESP32 (傘に搭載) ]
  │
  │ (BLE スキャン & RSSI強度による距離判定)
  │ 近い(-70以上) → ロック解除 / 遠い(-85以下) または 15秒ロスト → ロック
  ▼
[ サーボモーター ] -> 傘のロック機構を物理的に制御 (0度 / 180度)

## 背景・課題

コンビニエンスストアや公共施設での「傘の盗難・取り間違い」は日常的に発生するストレスの多い課題です。
しかし、傘に物理的なダイヤルロックや南京錠をつけるのは、雨の日に手荷物がある状態では非常に手間がかかります。そこで、「持ち主が離れるだけで勝手に鍵がかかり、戻ってくると勝手に開く」という、ユーザーに一切の操作を要求しないシームレスなセキュリティ体験を提供したいと考え、本プロダクトを開発しました。

## 工夫した点・こだわった点

ハンズフリー自動ロック/アンロック機能

スマホから発信されるBLE電波の強度（RSSI）をESP32が検知し、距離に応じてサーボモーターを自動制御します。

Android専用バックグラウンド発信アプリ

OSの厳しいタスクキルを回避し、画面を閉じてポケットに入れたままでも安定してUUIDを発信し続けます。

チャタリング（誤作動）防止ロジック

電波の瞬断による鍵のカシャカシャとした誤作動を防ぐため、15秒間のタイムアウト猶予を持たせたフェイルセーフ機能を実装しています。

## 今後の展望

アプリからの距離（感度）調整機能の実装

アプリのUI上にスライダーなどを設け、送信出力（Tx Power）を変更することで、ユーザーが「どのくらいの距離でロック/アンロックさせるか」を自由にカスタマイズできるようにしたいです。

ハードウェアの小型化と省電力化

傘の柄に内蔵できるレベルへの基板の小型化や、ディープスリープを活用したESP32のバッテリー寿命の延長。
